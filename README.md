# UC7-projeto-backend-web

# Plataforma de Cursos

Projeto desenvolvido na UC7.

## Funcionalidades

- Cadastro de usuários
- Login
- Consulta de cursos

## Tecnologias

- Python
- Django
- Git
- GitHub

## Objetivo do projeto
Permitir que os usuários realizem seu cadastro de usuários, depois permite acessar o sistema via login e realizar consulta de cursos na plataforma.

## Público-alvo
Estudantes, professores, diretores, coordenadores, servidores e responsáveis pelos alunos.

## Futuras melhorias
Realizar compras de materiais escolares, ver notas de aluno, emitir relatórios diversos.
